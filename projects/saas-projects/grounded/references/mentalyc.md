# Mentalyc: AI Documentation Platform for Mental Health Professionals

## Overview
Mentalyc is an AI-powered clinical documentation platform designed for therapists, counselors, psychiatrists, and behavioral health professionals. The core value proposition centers on automating therapy documentation to reclaim clinician time.

**Tagline:** "Be fully present. Leave with everything done."

## Key Product Features

### 1. AI Note Taker
- Generates clinical notes in multiple formats: SOAP, DAP, BIRP, GIRP, PIRP, PIE, progress notes, intake notes, and supervision/consultation notes
- Supports diverse client types: individual, group, couples, families, child, and supervisee sessions
- Works with telehealth recordings, audio uploads, dictation, or typed summaries

### 2. AI Treatment Planner
- Auto-drafts treatment plans from session content
- Extracts SMART goals discussed during sessions
- Maintains goal-to-progress note linkage across time

### 3. AI Progress Tracker
- Automatically extracts and trends goal progress and symptom changes from sessions
- Eliminates need for separate client questionnaires
- Generates longitudinal visualizations (e.g., "Anxiety · last 6 sessions")

### 4. Alliance Genie™
- Derives therapeutic alliance scores from session language rather than client questionnaires
- Flags relationship ruptures and repairs
- Surfaces alliance trends over time

## Differentiation Claims
Mentalyc positions itself against:
- Generic EHR AI features: notes isolated per session; no cross-session structure
- ChatGPT for therapists: not HIPAA-compliant, no EHR integration, no BAA, trains on user data
